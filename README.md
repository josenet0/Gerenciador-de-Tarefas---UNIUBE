# 📝 Gerenciador de Tarefas Moderno

Este é um projeto de gerenciamento de tarefas desenvolvido com as tecnologias mais recentes do ecossistema React. O foco principal foi a aplicação de **Testes Automatizados** e o uso do **React 19**.

## 🚀 Tecnologias Utilizadas

- **React 19**: Uso de hooks modernos e alta performance.
- **Jest & React Testing Library**: Cobertura de testes para garantir a confiabilidade da UI.
- **Web Vitals**: Monitoramento de performance e saúde da aplicação.
- **ESLint**: Padronização e qualidade de código.

## 🛠️ Funcionalidades

- Adição, edição e exclusão de tarefas.
- Filtros de status (Concluídas / Pendentes).
- Interface responsiva e otimizada.
- Validação de entradas para evitar dados inconsistentes.

📦 Como rodar o projeto
Clone o repositório:
1 - git clone 
2- Instale as dependências:npm install
3- Inicie a aplicação: npm start
